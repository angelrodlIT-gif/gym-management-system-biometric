# Gym System

Sistema de administración para gimnasios desarrollado en C# .NET Framework.

## Características

- Registro de miembros
- Gestión de membresías
- Control de acceso
- Registro biométrico
- Verificación mediante huella DigitalPersona
- SQL Server

## Tecnologías

- C#
- .NET Framework
- SQL Server
- WinForms
- WPF
- DPUruNet SDK

## Requisitos

- Visual Studio 2022
- SQL Server Express
- DigitalPersona SDK
- Lector U.are.U 4500

## Base de datos

Restaurar el archivo:

SistemaGimnasio.bak

Modificar la cadena de conexión en:

App.config


## DLLS SDK
Las DLLs son de un SDK comercial. El usuario debe instalar el SDK de DigitalPersona U.are.U
